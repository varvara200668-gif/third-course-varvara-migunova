1. Растеризация - это перевод геометрической фигуры в пиксели.
2. Берётся max dx и dy, чтобы по основной оси двигаться на один пиксель за шаг, а по другой - не больше чем на один.
3. У пикселей целые координаты, а при вычислении получаются дробные. Поэтому выбираем ближайший пиксель округлением.
4. Нарисуется одна точка.
5. В ЦДА есть деление и округление, используются дробные числа. При сложении накапливается погрешность.

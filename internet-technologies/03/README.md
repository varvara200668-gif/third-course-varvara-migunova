1. Endpoint используется https://jsonplaceholder.typicode.com/users, оттуда загружается список пользователей.

2. Отправляется GET. В fetch он отдельно не написан, потому что используется по умолчанию.

3. Состояние хранится в объекте state в файле app.js. Там массив пользователей, загрузка, ошибка и строка поиска.

4. Сначала список пустой, потом при запросе показывается «Загрузка...». Дальше либо пользователи, либо сообщение об ошибке. Если поиск ничего не нашёл, тоже выводится сообщение.

5. Ошибка обрабатывается в catch. Перед этим проверяется response.ok, а если ответ не успешный, то вызывается throw. Ошибка показывается на странице и загрузка заканчивается.

6. Фильтрация идёт по имени, username и email. Регистр не учитывается, исходный массив не меняется.

7. При успешном запросе в Network должен быть статус 200, метод GET и JSON с пользователями в Response. При проверке с адресом /users-wrong статус 404. Это можно увидеть у самого запроса, а на странице появится ошибка.

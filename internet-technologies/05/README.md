1. npm install всей папки 05
2. npm start
3. Задачи. Поля id, title, category, done
4. Получение списка задач, одной задачи, создание задачи и информация об API
5. Примеры:
выполненные задачи: /api/tasks?done=true выполненные задачи
поиск по названию: /api/tasks?q=API
оба фильтра вместе: /api/tasks?done=false&q=API
6. Корректная:
{
  "title": "Сдать лабораторную",
  "category": "Учеба"
}
    Ошибочная:
{
  "category": "Учеба"
}
7. Таблица

| Метод | URL | Описание | Возможные статусы |
|---|---|---|---|
| GET | /api/tasks | Список задач и фильтрация | 200, 400 |
| GET | /api/tasks/:id | Одна задача | 200, 404 |
| POST | /api/tasks | Создание задачи | 201, 400 |
| GET | /api/info | Информация об API и количество задач | 200 |
| Любой | Неизвестный маршрут | Ошибка: маршрут не найден | 404 |
